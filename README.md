# hitodor.app / hitodor.com — holding page

One static page, served by GitHub Pages, saying Hitochat is coming.

It exists because Hitodor's backend was shut down on 4 September 2026 and every
A record on both domains pointed at a Hetzner box that no longer exists. The
page is here rather than on a server because the point of the shutdown was to
stop running services — a VM kept alive to announce that nothing is running
would have been a joke at its own expense.

Source of truth for the markup is `web/holding/index.html` in the private
`hitodor` archive repository. This repo is public only because GitHub Pages on
a private repo needs a paid plan, and it holds nothing that isn't already on
the open internet.
